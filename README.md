# 🍩 3D Donut in Rust

A terminal-based, rotating 3D ASCII donut written in Rust — inspired by the classic
[`donut.c`](https://www.a1k0n.net/2011/07/20/donut-math.html) by Andy Sloane.

## Features

- Real-time 3D rendering directly in your terminal using ASCII characters
- Smooth rotation with luminance-based shading
- No external dependencies — pure Rust and the standard library <!-- adjust if you use crates -->
- Runs anywhere with a terminal

## Requirements

- [Rust](https://www.rust-lang.org/tools/install) (edition 2021 or later)
- A terminal that supports ANSI escape codes (any modern terminal works)
